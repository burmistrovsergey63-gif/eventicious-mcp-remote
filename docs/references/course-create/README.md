# Course Create Reference Files

Reference payloads and documentation for Eventicious course creation via MCP.

## Contents

- `course_create_reference_payload.json` — Full course skeleton payload (lowercase enum values)
- `course_create_reference_payload_pascal.json` — Same payload with PascalCase enums (MCP input format)
- `course_create_reference_payload_replay.json` — Replay variant of the payload
- `course_create_reference_request.md` — Endpoint, headers, and field documentation
- `course_create_reference_summary.md` — Quick summary of the reference course structure

## Notes

- No secrets or tokens are included in these files.
- These are reference documents, not executable scripts.
- The reference course demonstrates a full 13-stage skeleton with Common and Task stages.
